# 幸运硬币选择

> **V0.1.3.1** · 版本号唯一来源：[`config/version.json`](config/version.json)

用丢硬币的趣味游戏，帮你做出简单决策。

## 项目简介

小红书「小工具」。把日常决策包装成一场**丢硬币**趣味游戏：用户滑动硬币启动 3D 旋转，落定后正面 YES / 反面 NO——每次投掷就是一次独立决策。每次落定自动记入**战绩**（日期、时间与结果，本地持久化，刷新不丢），可随时回看或手动清零。交互趣味化优先，逻辑可解释、结果可复现。

## 技术平台

小红书「小工具」——运行在小红书 App 的 WebView 沙箱内，纯 HTML5 单页应用。

| 项       | 说明                                                |
| -------- | --------------------------------------------------- |
| 平台     | 小红书（Xiaohongshu / RedBook）                     |
| 容器     | WebView（Chromium ≥ 93），独立 iframe 沙箱          |
| 技术栈   | HTML + CSS + JavaScript（无后端）                   |
| 部署方式 | PC 上传（创作者中心 → Builder Hub）或移动端笔记挂载 |
| 更新方式 | 纯前端改动无需客户端发版（新增/移除 JS API 除外）   |

### 能力边界（来源：`reference/redbooksmalltools.pdf`）

**可用：** CSS3 动画/过渡（硬币 3D 旋转首选）、Canvas 2D（性能兜底）、SVG、fetch/XHR/WebSocket、localStorage/sessionStorage、触摸/手势事件、传感器、位置信息（需授权）

**禁用：** WebGL、WebAssembly、Web Workers（离线包模式）、eval()/new Function()、document.write()、内联事件处理、动态加载外部 JS（白名单外）、WebRTC 等

## 特性

- 🪙 **3D 硬币旋转**：左右滑动启动，多次滑动加速，减速后期精确落在结果面（CSS3 3D 双面翻转，币面 YES/NO 冲压字）
- 🏷️ **标题行**：常驻「幸运硬币」+ 一句话说明，首屏 5 秒认知
- 🎨 **四季主题**：春 / 夏 / 秋 / 冬四套场景（背景+配色+装饰），默认跟随季节自动切换，也可手动选择并记住
- 🐈 **双猫陪伴**：小黑（德文奶牛母猫）与小白（德文纯白公猫），待机浮动、落定欢呼
- 📋 **战绩记录**：每次落定记录日期、时间与 YES/NO（金/银圆点），localStorage 持久化，刷新/重开不丢
- 🧹 **手动清零**：战绩浮窗内「清除全部战绩」，页内二次确认防误触
- 🔄 **可解释可复现**：随机源与种子明确，结果可复现
- 📱 **单屏自适应**：强制单屏布局（320-430px 断点），安全区适配，桌面 480px 居中

## 快速开始

### 本地预览

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

### 部署（小红书小工具）

1. 进入 [小红书创作者中心](https://creator.xiaohongshu.com)
2. 左侧菜单 → Builder Hub → 小工具
3. 点击「创建小工具」，填写名称/简介/图标
4. 上传小工具资源包（HTML/CSS/JS，依赖须内嵌）
5. 提交审核，通过后即可在笔记中挂载使用

## 使用说明

1. 在硬币上左右滑动启动旋转，多次滑动可加速
2. 停止滑动数秒后提示"是决定的时候了"，硬币自动减速落定（正面 YES / 反面 NO）
3. 每次落定自动记入战绩（日期 时间 + YES/NO），结果面停留后硬币翻转回展示面，可直接继续下一次投掷
4. 点击「战绩」查看全部历史记录（最新在上，空态显示"暂无战绩"）；刷新/重开不丢失
5. 点击「战绩」浮窗底部「清除全部战绩」，再按一次确认即可清零
6. 点击「换主题」选择四季主题（春/夏/秋/冬），或开启「跟随季节自动切换」（3-5 春 / 6-8 夏 / 9-11 秋 / 12-2 冬）

## 常见问题

### 为什么不用 WebGL？

小红书小工具容器出于安全考虑禁用了 WebGL。硬币 3D 翻转动画通过 CSS3 `perspective` + `transform: rotateY()` + `transform-style: preserve-3d` 实现，性能和流畅度完全够用。

### 离线包是什么？

小红书会将小工具的前端资源（HTML/CSS/JS）通过 CDN 加速并缓存到本地。离线时静态资源仍可用，但网络请求（fetch/XHR/WebSocket）需要网络。

### 如何更新小工具？

纯前端改动（不涉及新增/移除 JS API）无需客户端发版，重新上传资源包即可生效。
