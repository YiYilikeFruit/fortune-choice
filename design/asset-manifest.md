## 四、动效规格（game-feel 审查落地）

| 事件               | 反馈包（组合）                                 | 时长/曲线                                                      |
| ------------------ | ---------------------------------------------- | -------------------------------------------------------------- |
| 落定（large）      | 硬币 bounce + 结果丝带 pop + 猫咪欢呼 + 彩纸屑 | 150ms / 320ms `cubic-bezier(0.34,1.56,0.64,1)` / 420ms / 900ms |
| 按钮按下（small）  | 位移 4px + 阴影压缩                            | 90ms ease-out                                                  |
| 浮窗开启（medium） | sheet 滑入 24px + 透明度                       | 200ms ease-out                                                 |
| 猫咪待机（生命感） | 上下浮动 5px                                   | 3.2–3.6s ease-in-out 循环                                      |
| 战绩录入           | 列表首行高亮（可选）                           | 300ms                                                          |

统一：只动 `transform/opacity`；`prefers-reduced-motion` 下关闭花瓣、猫咪浮动、丝带 pop、彩纸屑。

## 五、生成工作流

1. 按 2.1 生成 4 张背景（9:21，1K）→ 裁 9:19.5 → WebP
2. 按 2.2 生成 6 张角色（白底，1K）→ 抠图 → 裁尺寸 → WebP
3. 按 2.3 生成 4 张缩略图（4:3，1K）→ 裁 320×240 → WebP
4. 素材入 `assets/ui|cats|thumbs/`，替换 prototype.html 占位
5. 四季逐张校对（构图、色彩、遮挡）后，再落地项目实现
